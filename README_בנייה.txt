בניית SessionChecker כקובץ exe (Windows) ו-app (Mac) באמצעות GitHub Actions
=========================================================================
1. צרו מאגר פרטי חדש ב-GitHub והעלו אליו את כל תוכן התיקייה הזו (כולל התיקייה הנסתרת .github).
2. בלשונית Actions בחרו "Build SessionChecker" ולחצו Run workflow. הבנייה לוקחת כמה דקות.
3. בסיום, בתחתית דף הריצה, תחת Artifacts, הורידו SessionChecker-windows-latest (ו/או macos-latest).
4. חלצו את ה-zip. ההרצה: SessionChecker.exe (או SessionChecker ב-Mac). נפתח דף בדפדפן.
הערות: ההפעלה הראשונה איטית, Windows יציג אזהרת SmartScreen (More info > Run anyway) כי הקובץ אינו חתום.
